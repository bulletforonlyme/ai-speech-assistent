# ️ AI Voice Assistant

Голосовой ассистент с распознаванием речи и AI-ответами в реальном времени. Слушает микрофон, автоматически определяет речь, распознаёт её и отвечает через языковую модель.

![Python](https://img.shields.io/badge/Python-3.10+-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

## ✨ Возможности

- **🎤 Автоматическое обнаружение речи (VAD)** — программа сама понимает, когда ты начал и закончил говорить
- **🧠 Умный буфер предзаписи** — не обрезает начало фразы, даже если ты заговорил внезапно
- **📝 Распознавание речи** через Deepgram Nova-2 (отличное качество для русского языка)
- **🤖 AI-ответы** через Groq (Llama 3, Mixtral, Qwen и др.)
- **🎨 Графический интерфейс** на Tkinter с индикатором уровня звука
- ** Быстрая реакция** — ответ через 1-2 секунды после окончания фразы
- **🔄 Бесконечный цикл** — слушает непрерывно, без необходимости перезапуска
