# ️ AI Voice Assistant

Голосовой ассистент с распознаванием речи и AI-ответами в реальном времени. Слушает микрофон, автоматически определяет речь, распознаёт её и отвечает через языковую модель.

![Python](https://img.shields.io/badge/Python-3.10+-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

## ✨ Возможности

- **🎤 Автоматическое обнаружение речи (VAD)** — программа сама понимает, когда ты начал и закончил говорить
- **🧠 Умный буфер предзаписи** — не обрезает начало фразы, даже если ты заговорил внезапно
- **📝 Распознавание речи** через Deepgram Nova-2 (отличное качество для русского языка)
- **🤖 AI-ответы** через Groq (Llama 3, Mixtral, Qwen и др.)
- **🎨 Графический интерфейс** на Tkinter с индикатором уровня звука
- ** Быстрая реакция** — ответ через 1-2 секунды после окончания фразы
- **🔄 Бесконечный цикл** — слушает непрерывно, без необходимости перезапуска


## 🚀 Быстрый старт

### 1. Клонируй репозиторий

```bash
git clone https://github.com/ТВОЙ_НИК/ai-voice-assistant.git
cd ai-voice-assistant
```

### 2. Создай виртуальное окружение

```bash
python -m venv venv
venv\Scripts\activate  # Windows
# source venv/bin/activate  # macOS/Linux
```

### 3. Установи зависимости

```bash
pip install -r requirements.txt
```

### 4. Настрой API ключи
Создай файл .env в корне проекта и добавь свои ключи:

```bash
DEEPGRAM_API_KEY=твой_ключ_deepgram
GROQ_API_KEY=твой_ключ_groq
```

Где взять ключи:
Deepgram: зарегистрируйся на console.deepgram.com → API Keys → Create Key (даёт $200 бесплатных кредитов)
Groq: зарегистрируйся на console.groq.com → API Keys → Create Key (бесплатный тариф с лимитами)

### 5. Запусти

```bash
python ai_assistant_ui.py
```

⚙️ Настройка
Выбор микрофона
При запуске в выпадающем списке "Microphone" выбери нужное устройство. Программа автоматически предложит устройство по умолчанию.

Параметры VAD
В начале файла ai_assistant_ui.py можно настроить чувствительность:

VAD_THRESHOLD = 0.015      # Порог срабатывания (0.01 - чувствительно, 0.05 - только громкие звуки)
SILENCE_DURATION = 1.5     # Секунд тишины до остановки записи
PRE_RECORD_BUFFER_SEC = 1.0 # Сколько секунд хранить в памяти ДО начала речи

Рекомендации:
Если программа не слышит тебя → уменьши VAD_THRESHOLD до 0.01
Если срабатывает на шумы → увеличь до 0.03
Если обрывает фразы → увеличь SILENCE_DURATION до 2.0

🛠 Технологии
Python 3.10+ — язык программирования
Tkinter — графический интерфейс
sounddevice — захват звука с микрофона
Deepgram API — распознавание речи (модель Nova-2)
Groq API — языковые модели (Llama 3, Mixtral, Qwen)
numpy — обработка аудио

🔒 Безопасность
⚠️ Никогда не коммить реальные API ключи в репозиторий!
Используй переменные окружения или .env файл (добавлен в .gitignore). В коде примера ключи захардкожены только для демонстрации — замени их на загрузку из .env

🐛 Решение проблем
Программа не слышит микрофон
Проверь, выбрано ли правильное устройство в выпадающем списке
Убедись, что микрофон не используется другим приложением
Попробуй уменьшить VAD_THRESHOLD
Ошибка 401 от Deepgram/Groq
Проверь, что API ключи правильные и не истекли
Убедись, что на аккаунте есть доступ к API
Задержка перед ответом
Уменьши SILENCE_DURATION в настройках
Проверь скорость интернета (аудио отправляется в облако)
